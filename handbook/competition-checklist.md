# Competition Checklist

Copy this into a GitHub issue for each event (`[Event] Pack & prep — <event name>`) so people
can check items off and assign owners.

> Logistics with names (rooms, rides, permission slips) live in the **coaches' Drive**, not here.

## 2 weeks before

- [ ] Event registered; schedule posted in **Robotics — Competition** Chat space
- [ ] All students' FIRST consent forms complete *(coaches verify in the FIRST dashboard)*
- [ ] School permission / travel forms collected *(coaches, in Drive)*
- [ ] Robot weighed and within the current weight limit **without bumpers and battery**
- [ ] Bumpers built per current rules; both colors; team number legible
- [ ] Spare parts list reviewed; order anything missing
- [ ] Robot code on `master` builds and has been tested on the robot
- [ ] Driver Station laptop updated (FRC Game Tools, current season image)
- [ ] Radio programmed / firmware current per event requirements

## Pack list

**Robot**
- [ ] Robot + cart
- [ ] Bumpers (red + blue)
- [ ] Batteries (all) + chargers + battery cart
- [ ] Driver Station laptop + charger, controllers, Ethernet cable, USB cables

**Tools**
- [ ] Hex keys (SAE), wrenches, screwdrivers, pliers, flush cutters
- [ ] Drill/driver + bits, rivet tool + rivets
- [ ] Zip ties, electrical tape, Velcro, thread locker
- [ ] Crimpers, wire, Anderson contacts, ferrules, multimeter
- [ ] Spare fasteners bin

**Spares**
- [ ] Spare motor + motor controller
- [ ] Spare swerve module parts / wheels / belts
- [ ] Spare roboRIO / radio *(if we have them)*
- [ ] Spare CAN cable, PWM cable, breakers

**Pit**
- [ ] Safety glasses (extras for visitors!)
- [ ] First-aid kit, battery spill kit
- [ ] Power strips, extension cords
- [ ] Team banner, pit display, printed handbook pages
- [ ] Scouting devices/sheets

## At the event

- [ ] Pass **inspection** early on day 1 (bring the robot, bumpers, and a battery)
- [ ] Check in, find the pit, set up
- [ ] Practice matches: test auto, check connection on the field
- [ ] Between matches: battery swap, quick mechanical check, review match video
- [ ] Keep the pit clean and safety glasses on — the Safety Award is judged

## Between-match quick check

- [ ] Fresh battery, strapped in
- [ ] Bumpers correct color, secure
- [ ] Wheels/modules spin freely, no loose bolts
- [ ] Wires secure, no damage
- [ ] Correct autonomous selected

## After the event

- [ ] Write a short **lessons learned** in `team/events/` (what broke, what worked)
- [ ] Add any new fixes to [Troubleshooting](troubleshooting.md)
- [ ] Open issues for repairs/improvements
