# How We Communicate

Blue Tide uses three tools. Each has one job.

| Tool | Job | Examples |
|---|---|---|
| 💬 **Google Chat** | Talk *right now* | "Running 10 min late", "anyone have the 5/32 hex key?", ride sign-ups |
| 🐙 **GitHub** | Track work and **keep** knowledge | Build tasks, bugs, design decisions, how-tos, code |
| 📁 **Google Drive** | School-style documents | Permission slips, budgets, sponsor letters, big photo/video files |

> **Chat is where we coordinate. GitHub is where we remember.**
> If a Chat conversation produces an answer the team will need again, someone turns it into an
> issue, a doc update, or a troubleshooting entry. Chat history is not the archive.

## Google Chat spaces

| Space | For |
|---|---|
| **Robotics — General** | Announcements, schedules, whole-team stuff |
| **Robotics — Mechanical** | Build, CAD, fabrication |
| **Robotics — Programming & Electrical** | Code, wiring, controls |
| **Robotics — Competition** | Event logistics, pit, scouting (active during season) |

- Reply **in the thread**, not as a new message, so topics stay together.
- Important links (this handbook, the season calendar, the task board) are **pinned** in each space.
- Use `@mention` sparingly — only when you need that person specifically.

## GitHub

- **Issues** = a task, bug, or question that needs an owner. Use the templates.
- **Projects board** = what's being worked on this week, and by whom.
- **Pull requests** = proposed changes to docs or code, reviewed before merging.
- Turn on notifications: **Watch** this repo (top-right) → *Participating and @mentions* at minimum.

## Ground rules (FIRST Youth Protection)

Team 2840 follows the [FIRST Youth Protection Program](https://www.firstinspires.org/resource-library/youth-protection-policy):

- **Adults and students communicate in team spaces, not private 1-on-1 messages.** If an adult
  needs to message a student individually, another adult or the student's parent is included.
- Keep it school-appropriate — everything in team spaces is visible to coaches.
- Personal info (phone numbers, addresses, medical, travel status) **never** goes on GitHub.
  It goes to coaches via Drive or email.

## "Where do I put this?" quick guide

- Question you need answered today → **Chat**
- "We should fix/build/buy X" → **GitHub issue**
- "Here's how to do X" → **Handbook doc (PR)**
- "We decided X because Y" → **issue comment or doc** so the reasoning survives
- Form with someone's name on it → **Drive**
