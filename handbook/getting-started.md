# Getting Started on Blue Tide

Welcome to FRC Team 2840! This page gets you set up in your first week.

## 1. Accounts you need

| Account | What it's for | How |
|---|---|---|
| **School Google account** | Team Google Chat spaces + shared Drive | You already have it |
| **GitHub** | This handbook, robot code, tasks | Sign up at [github.com](https://github.com/signup), then send your username to a coach to join the `PCDSBlueTide` org |
| **FIRST** | Registration, consent forms (required to compete) | [firstinspires.org](https://www.firstinspires.org) → register as a youth member of Team 2840 |
| **Onshape / Fusion** *(CAD folks)* | Robot CAD | Ask the mechanical lead |

> 💡 Pick a GitHub username you'd be OK with a college or employer seeing. Many people use
> some version of their real name — it becomes a portfolio.

## 2. Where things live

- **Google Chat** — day-to-day talk. See [How We Communicate](communication.md).
- **This repo** — how-tos, standards, checklists, season notes.
- **GitHub Issues / Projects** — the build task list.
- **Google Drive** — forms, paperwork, big media files.

## 3. Your first week checklist

- [ ] Read [Shop Safety](safety.md) and get signed off by a mentor
- [ ] Join the Google Chat spaces (a coach will add you)
- [ ] Join the `PCDSBlueTide` GitHub org
- [ ] Complete FIRST registration + consent forms
- [ ] Read [GitHub Basics](github-basics.md) and [Planning Board](planning-board.md)
- [ ] **Make your first contribution:** find one thing in this handbook that's confusing,
      wrong, or missing, and open an issue or a pull request about it

## 4. Sub-teams

| Sub-team | Does | Start reading |
|---|---|---|
| Mechanical / CAD | Design and build the robot | [Mechanical standards](mechanical-standards.md) |
| Programming | Robot code, vision, autonomous | [Programming setup](programming-setup.md) |
| Electrical | Wiring, power, CAN, sensors | [Electrical standards](electrical-standards.md) |
| Business / Media | Sponsors, outreach, awards, social | *(doc coming — want to write it?)* |
| Strategy / Scouting | Game analysis, match scouting | *(doc coming — want to write it?)* |

It's normal to try more than one. Ask a lead to shadow them for a meeting.

## 5. Who to ask

- **Technical question?** Ask in the sub-team's Chat space first. If the answer is useful to
  others, help get it into [Troubleshooting](troubleshooting.md).
- **Schedules, forms, travel?** A coach.
- **Something feels unsafe or wrong?** Tell any coach immediately.
